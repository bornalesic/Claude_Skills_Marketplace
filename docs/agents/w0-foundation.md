# Brief: W0 foundation

**Branch:** `ws/w0-foundation` · **Phase:** 0 (runs alone) · **Ports:** 3010 / 3011 · **DB:** `upskillzz_w0`

## Mission

Turn this documentation-only repo into a working monorepo that five agents can build in at the same time: tooling, shared types, database schema, and empty but running app skeletons. Everything you produce is a foundation others code against, so match the contracts exactly and keep it boring.

## Read first

- `docs/contracts/database.md`, `interfaces.md` (the `@upskillzz/shared` and `@upskillzz/db` sections), `content-format.md`, `env.md`, `http-routes.md`, `mcp.md` (routes only)
- `docs/WORKSTREAMS.md` (you create the skeleton files others will own)
- `packages/shared/CLAUDE.md`, `packages/db/CLAUDE.md`, `apps/web/CLAUDE.md`, `apps/mcp/CLAUDE.md`

## You own

Root configs (`package.json`, `pnpm-workspace.yaml`, `turbo.json`, `tsconfig.base.json`, `biome.json`, `.nvmrc`, `.gitignore`, `.env.example`), `scripts/**`, `.github/workflows/ci.yml`, `packages/shared/**`, `packages/db/**` (including the first version of `schema/auth.ts`), `content/package.json`, `infra/docker-compose.dev.yml`, `infra/postgres-init/**`, and the initial skeletons of `apps/web`, `apps/mcp`, `packages/auth`, `packages/content`, `packages/entitlements`, `packages/payments`, `e2e` (just enough to build; ownership passes to their workstreams when you merge).

Don't change the docs. If a contract looks wrong, write a contract change request in your status file and follow the current version.

## Verify before building

Check the current docs for: pnpm workspaces and Turborepo, Next.js (latest stable: App Router, MDX setup, whether the request middleware file is `middleware.ts` or `proxy.ts`), Tailwind CSS and shadcn/ui init, Drizzle ORM and drizzle-kit with postgres.js, Better Auth CLI schema generation for Drizzle (`https://better-auth.com/docs`), Better Auth MCP plugin (`https://better-auth.com/docs/plugins/mcp`) for the plugin list, Biome, Vitest workspaces. Pin exact versions in `package.json`.

## Deliverables

1. **Workspace.** pnpm workspace containing `apps/*`, `packages/*`, `content`, `e2e`. Turborepo tasks `build`, `dev`, `test`, `typecheck`, `lint` with correct dependencies and caching. `tsconfig.base.json` with strict mode, `noUncheckedIndexedAccess`, ESM, path-free package imports (packages resolve through workspace links). Biome for lint and format. Vitest configured per package.
2. **Env loading.** Every app and CLI loads the worktree root's `.env.local`, then validates with `parseEnv`. `pnpm dev` starts web on `WEB_PORT` and MCP on `MCP_PORT`.
3. **`@upskillzz/shared`.** Everything in its section of `interfaces.md`: regexes, constants, Zod schemas for `skill.yaml`, SKILL.md frontmatter, pack YAML (all rules in `content-format.md`), public catalog types and schema, `defineAction`, `parseEnv`, `formatPrice`, `AppError`, `claudeAddConnectorUrl`, `claudeCodeAddCommand`. Unit tests for every schema rule (valid and invalid examples).
4. **`@upskillzz/db`.** Drizzle schema for every app table and enum in `database.md` (`schema/catalog.ts`, `schema/commerce.ts`, `schema/usage.ts`), including the unique index with `NULLS NOT DISTINCT` and the order item check constraint. `schema/auth.ts` generated with Better Auth's CLI from a config using the same plugins W1 will use (Google provider, JWT plugin, `@better-auth/mcp`, `@better-auth/cimd`, DCR enabled); note in your status file exactly how you generated it so W1 can regenerate. `createDb`, `withTestDb`. `drizzle.config.ts`. The first migration in `packages/db/migrations/` (this is the only migration not generated by the orchestrator).
5. **Database scripts.** `pnpm db:up` (Docker Compose Postgres 17 from `infra/docker-compose.dev.yml`, with an init script in `infra/postgres-init/` that creates `upskillzz` and `upskillzz_w0` to `upskillzz_w8`), `db:down`, `db:push`, `db:generate`, `db:migrate`, `db:reset` (drop and recreate this worktree's database, push, content sync).
6. **App skeletons.**
   - `apps/web`: Next.js App Router, TypeScript, Tailwind, shadcn/ui initialised, MDX enabled for `src/content/**`, placeholder page for every route in `http-routes.md` (a heading and "TODO"), `GET /api/health` per the contract, folder structure from `apps/web/CLAUDE.md`. It must build.
   - `apps/mcp`: Hono on Node with `GET /healthz` per the contract and `POST /mcp` returning `501` for now; `src/env.ts`; `tsx watch` dev script; build to `dist/`.
   - `packages/auth`, `packages/content`, `packages/entitlements`, `packages/payments`: `package.json` with the export entry points listed in `interfaces.md` (including subpaths `@upskillzz/auth/verify`, `@upskillzz/content/catalog`, `@upskillzz/content/actions`), a `src/index.ts` exporting typed stubs that throw `new Error("not implemented: <name>")`, and one passing placeholder test each. Owners replace these.
   - `content/package.json` (`@upskillzz/content-src`, private) depending on `@upskillzz/shared` and `zod`, so action files type-check.
   - `e2e/`: Playwright installed and configured, one smoke test that loads `/` (W8 owns it afterwards).
7. **Root scripts** exactly as in the README commands table, including `content:validate`, `content:build`, `content:sync` (they can print "not implemented" until W3 merges, but must exist), and `e2e`.
8. **CI.** `.github/workflows/ci.yml` on pull requests and pushes to main: install with cache, typecheck, lint, test (with a Postgres service container), build, `content:validate`.

## Acceptance checks

- On a fresh clone of your branch: `pnpm install && pnpm db:up && pnpm db:push && pnpm build && pnpm test && pnpm typecheck && pnpm lint` all pass.
- `pnpm dev` serves `http://localhost:3010/` and `http://localhost:3011/healthz` returns `200 {"ok":true}`.
- `GET http://localhost:3010/api/health` returns `200 {"ok":true}`.
- Every table, column, enum and index in `database.md` exists in your migration.
- Every export in the `@upskillzz/shared` section of `interfaces.md` exists with the stated types.
- The README commands table matches the scripts that exist.
